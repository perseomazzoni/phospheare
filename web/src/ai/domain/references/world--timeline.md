The writer's timeline: the story's present, how time is measured, and each past event or period by name, with when it happened, what happened, its effects, and how it is remembered.

The present and each event's date and content are established facts: an age, an interval or a date the pages give against them is a slip. How time is measured is a rule the pages keep. How an event is remembered is belief: a character remembering it differently is no slip.

Compare the prose against the prose, and the prose against the project's reference documents and notes. Two reference items that contradict each other are reported for the writer to resolve rather than decided between.
Hold every fact the prose states against every other place the book states it: each name; each age; each date and weekday; each clock time; each distance and journey time; each person's looks (hair, eyes, build), job, past and family; and each object's colour, owner and place. A fact said once, in one Section, is exactly where a slip hides: grep the book for it and read around each place it comes back before you conclude it holds. When the book gives a list of the facts it states, each with the other places that state it differently, check every entry on it: it is drawn from the text by the app, it is not a finding, and a difference on it can be two different things.
